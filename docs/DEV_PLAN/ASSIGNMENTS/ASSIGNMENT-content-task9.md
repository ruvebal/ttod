# Assignment — Team 1, Task 9: Document one real design decision (taxonomy, fallback policy) for the oral defense

**Seam:** content · **Team:** 1 · **Task:** 9 of ~10
**Area(s):** Content/i18n/Proposals UI · **Verb served:** question

For Team 1, this task requires selecting one concrete architectural choice made during the implementation of the Content/i18n/Proposals UI—such as the specific taxonomy structure used for wisdom facets or the fallback policy applied when a translation key is missing—and preparing a defense that articulates the rejected alternative.
