The product journey

The reference follows one visible path: a localized route renders governed content; an Astro page establishes the document; Svelte or React adds bounded interaction; a request crosses an explicit API contract; retrieval returns a canonical quote; the browser exposes accessible state; and a test owns each meaningful risk.

That path is complete in the instructor reference. The proposed student baseline keeps the same path while reducing advanced areas to small, working examples that students must design and extend themselves.
