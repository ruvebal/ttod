# Assignment — Team 1, Task 7: Open one PR into a module you don't own

**Seam:** content · **Team:** 1 · **Task:** 7 of ~10
**Area(s):** Content/i18n/Proposals UI · **Verb served:** contribute

For Team 1, this means stepping outside the `src/content` or `src/pages/[locale]/wisdom` boundaries you have been working in to submit a genuine fix or small enhancement to a module owned by another team—such as the Graph, Oracle, or Accounts modules. This is not a drive-by typo commit; it requires you to read and modify code you did not write, demonstrating that you can navigate and contribute to the broader codebase. This task is graded as process evidence, not extra credit, and it is the one task that genuinely cannot be one-shotted by an AI coding assistant.

See the shared explanation: docs/public/teaching/tasks.md#the-three-recurring-tasks

> "The master teaches by example, not by perfection."
> — TTOD `ux-004`, *ux*

This task embodies the principle that learning happens through the act of contributing to real code, not just by observing perfect examples.
