# Assignment — Team 2, Task 8: Open one PR into a module you don't own

**Seam:** graph · **Team:** 2 · **Task:** 8 of ~10
**Area(s):** Cross-module · **Verb served:** contribute

For Team 2 (Knowledge Graph), this task means stepping outside the `components/graph` boundary to contribute a genuine fix or enhancement to a sibling module such as `services/frontend/src/pages/[locale]/wisdom/` or `services/frontend/src/auth/`, where your understanding of data relationships can improve how content is displayed or how user sessions are managed. This is not a drive-by typo commit; it is a deliberate act of reading and modifying code you did not write, serving as process evidence that you can navigate and respect the boundaries of a modular system.

See the shared explanation: docs/public/teaching/tasks.md#the-three-recurring-tasks

> "The module that knows its boundaries serves the whole. The module that knows no boundaries becomes the whole—and collapses under its own weight."
> — TTOD `arch-001`, *architecture*

This task enforces that discipline by requiring you to respect the boundaries of modules you do not own, ensuring your contributions strengthen the whole system rather than blurring its structural integrity.
