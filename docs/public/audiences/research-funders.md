# Invest in the questions, not an inflated claim

TTOD combines a governed pedagogical corpus, a working local front-end reference, a planned teaching-baseline refactor, and a cautious educational research agenda. It is not presented as a validated learning intervention, a public software service, or evidence of market adoption.

## Assets today

- A governed multilingual quote model with provenance and rights metadata.
- A command-line governance surface and derived data views.
- A locally observed end-to-end instructor application.
- A gated plan for a smaller student-owned product baseline.
- A research preparation layer that distinguishes feasibility, assessment, and consented research evidence.
- Split licensing: MIT code and predominantly CC BY-NC-SA content.

## Readiness and risk

| Dimension | Current position | Material gate |
| --- | --- | --- |
| Technical feasibility | local reference exists | independent verification and release hardening |
| Teaching product | specified, not yet delivered | subtraction refactor and learner rehearsal |
| Research | pre-protocol | ethics, data governance, method, and institutional review |
| Public application | not cloud deployed | separate product and operations decision |
| Public documentation | separable from application | Pages build, privacy gate, and editorial review |
| Commercial reuse | constrained by content license | rights and business-model analysis |

## Responsible partnership

Useful contributions include independent technical replication, accessibility evaluation, instructional-design review, bilingual editorial review, methodological supervision, ethics and data-governance expertise, and support for a properly bounded feasibility study.

Any venture discussion should begin with rights, stewardship, public-interest value, and the distinction between open code and non-commercial share-alike content. Forecasts, adoption, learning impact, and return are not asserted without evidence.
