# Assignment — Team 3, Task 8: Open one PR into a module you don't own

**Seam:** oracle · **Team:** 3 · **Task:** 8 of ~10
**Area(s):** Cross-Module Collaboration · **Verb served:** contribute

For Team 3, this task requires stepping outside the `oracle` seam to contribute a genuine fix or small enhancement to a module owned by another team (such as `content`, `graph`, or `accounts`). This is not a drive-by typo commit; it is a graded process evidence task that demands reading and modifying code you did not write, a skill that cannot be one-shotted by an AI assistant.

See the shared explanation: docs/public/teaching/tasks.md#the-three-recurring-tasks

> "Experience is simply the name we give to our bugs after we fix them."
> — TTOD `wis-001`, *wisdom*

This task forces you to encounter the "bugs" of another team's codebase, turning their experience into your understanding through the act of fixing.
